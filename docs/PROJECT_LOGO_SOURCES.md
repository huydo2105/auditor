# Opportunity logo sources

The eight bug bounty marks in `apps/web/public/projects/` were downloaded from the logo images on their corresponding [Immunefi program pages](https://immunefi.com/bug-bounty/). The page IDs are `aave`, `lido`, `metric`, `0x`, `orca`, `raydium`, `marinade`, and `pythnetwork`. They were checked on 17 November 2026 and stored locally as PNGs so the directory does not depend on a third-party image server at runtime.

Public-source entries reuse the corresponding bounty mark where the project matches. The other marks came from the public GitHub profiles for [OpenZeppelin](https://github.com/OpenZeppelin), [Uniswap](https://github.com/Uniswap), [Compound Finance](https://github.com/compound-finance), and [The Red Guild](https://github.com/theredguild). Solady uses its own [repository logo at the catalog's pinned revision](https://github.com/Vectorized/solady/blob/258f67cc71e39cff307b726939ade17e9d8bcf5c/logo.svg), rather than the maintainer's personal avatar.

These third-party marks identify the listed projects. Their appearance does not imply endorsement, program integration, or permission to test beyond the current official bounty rules.
